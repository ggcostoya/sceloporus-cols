Probability of recapturing adult lizards

To assess capture saturation and sampling completeness across field seasons, we filter the dataset for adult lizards (mean snout-vent length \(> 75\text{ mm}\)) and compute the cumulative number of unique individuals captured as a function of the day of the year (DOY) across sites and years.

Plot cummulative captures 
# filter adults
adults_by_site_year <- mr_data |>
  group_by(site, year, sex, id) |>
  summarise(avg_svl = mean(svl, na.rm = TRUE)) |>
  filter(avg_svl > 75) |>
  ungroup()

# filter mark-recapture data to include only adults
mr_data_adults <- mr_data |>
  semi_join(adults_by_site_year, by = c("site", "year", "sex", "id"))

# plot

Inter-annual survival probabilities

To evaluate population persistence across seasons, we compute empirical apparent survival probabilities for adult males by tracking whether an individual detected in a given year was recaptured in the subsequent year. The resulting annual survival rates are plotted across consecutive yearly transitions for high- and low-elevation populations.

Plot inter-annual survival probabilities

  rowwise() |>
  mutate(
    surv_next_year = as.numeric((year + 1) %in% all_years)

Home range estimation

We delineate individual home ranges by computing minimum convex polygons (MCP) via convex hulls (chull) using projected UTM coordinates. We retain individuals with at least 4 spatially-reference captures and filter out coordinate points \(> 150\text{ m}\) from each individual’s mean centroid to remove GPS artifacts and/or potential misidentifications. The resulting polygon coordinates are saved to data/home_ranges.rds and visualized with site-mean-centered coordinates to compare spatial extents across elevation sites.

home_ranges <- mr_data |>
  filter(if_all(c(lat, lon, utm_x, utm_y), ~ !is.na(.x))) |>
  group_by(site, id, sex) |>
  mutate(
    n_obs = n(),
    mean_utm_x = mean(utm_x),
    mean_utm_y = mean(utm_y),
    dist_to_center = sqrt((utm_x - mean_utm_x)^2 + (utm_y - mean_utm_y)^2)
  ) |>
  filter(
    dist_to_center <= 150,
    n_obs >= 4
  ) |>
  slice(chull(utm_x, utm_y)) |>
  ungroup() |>
  select(site, id, sex, utm_x, utm_y)

saveRDS(home_ranges, file = "data/home_ranges.rds")
