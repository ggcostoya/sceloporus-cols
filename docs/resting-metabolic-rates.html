Estimating Resting Metabolic Rates

Below we transform the raw respirometry data into resting metabolic rates (RMR) and mass-specific RMR for each individual. This process involves fitting linear models to the oxygen consumption data over time, extracting the slope as the RMR, and then normalizing by body mass to obtain mass-specific RMR. Further, we control-correct for background fluctuations in oxygen consumption by subtracting the slope of the control measurements.

Code 
rmr_data <- respirometry |>
  group_by(site, year, id, svl, mass, temp) |>
  summarise(
    rmr = coefficients(lm(o2 ~ trial_time))[2] * 60, # ml min-1
    rmr_control = coefficients(lm(o2_control ~ trial_time))[2] * 60 # ml min-1
  ) |>
  ungroup() |>
  mutate(
    rmr_mass_specific = - (rmr - rmr_control) / mass, # ml O2 min-1 g-1
  ) |>
  mutate(
    rmr_mass_specific = ifelse(
      rmr_mass_specific < 0, NA, # further removal of anomalus measurements
      rmr_mass_specific
    )
  ) |>
  mutate(log_rmr_mass_specific = log(rmr_mass_specific)) |>
  select(
    site, year, id, svl, mass, temp, rmr_mass_specific, log_rmr_mass_specific
  )

Estimating intercepts and slopes of RMR

Model description

Specification

We modeled the relationship between log mass-specific metabolic rate (\(R\)) and body temperature (\(T\)) using a hierarchical Bayesian framework to account for the nested structure of our data. Specifically, we modeled \(R\) as a linear function of \(T\) with individual-specific intercepts and slopes:

\[R_{i,j} \sim \mathcal{N}(\alpha_j + \beta_j \cdot T_{i,j}, \sigma)\]

Where \(R_{i,j}\) is the log mass-specific metabolic rate for the \(i\)-th measurement of the \(j\)-th individual, \(\alpha_j\) is the individual-specific intercept, \(\beta_j\) is the individual-specific slope (thermal sensitivity), and \(\sigma\) is the residual standard deviation.Because \(T\) was centered at 25°C, \(\alpha_j\) represents the log mass-specific metabolic rate of individual \(j\) at that reference temperature.

In turn, the individual-specific parameters \(\alpha_j\) and \(\beta_j\) were modeled as being drawn from population-level distributions:

\[\alpha_j = \alpha + \alpha_S S_j + \alpha_Y Y_j + \alpha_M M_j + \eta_{\alpha,j}\] \[\beta_j = \beta + \beta_S S_j + \beta_Y Y_j + \beta_M M_j + \eta_{\beta,j}\]

Where \(S_j\), \(Y_j\), and \(M_j\) represent the site, year, and body mass of individual \(j\), respectively, and \(\eta_{\alpha,j}\) and \(\eta_{\beta,j}\) are individual-level deviations from the population-level effects.

The individual-level deviations \(\eta_{\alpha,j}\) and \(\eta_{\beta,j}\) were modeled as being drawn from a multivariate normal distribution to account for the correlation between an individual’s baseline metabolic rate and its thermal sensitivity:

\[\begin{bmatrix} \eta_{\alpha,j} \\ \eta_{\beta,j} \end{bmatrix} \sim \text{MVN} \left( \mathbf{0}, \mathbf{\Sigma} \right)\]

Where \(\mathbf{0}\) is a vector of means and \(\mathbf{\Sigma}\) is the covariance matrix, defined as:

\[\mathbf{\Sigma} = \begin{bmatrix} \tau_{\alpha}^2 & \rho\tau_{\alpha}\tau_{\beta} \\ \rho\tau_{\alpha}\tau_{\beta} & \tau_{\beta}^2 \end{bmatrix}\]

Where \(\tau_{\alpha}\) and \(\tau_{\beta}\) represent the among-individual standard deviations for the intercept and slope, respectively, and \(\rho\) is the correlation coefficient between them.

Computational implementation

To ensure efficient sampling and avoid issues related to the geometry of the posterior distribution, we implemented the model using a non-centered parameterization. Instead of sampling the individual-level parameters \(\alpha_j\) and \(\beta_j\) directly from their respective group-level distributions, we treated them as transformed parameters. Specifically, we defined the vector of individual parameters \(\mathbf{\Theta}_j = [\alpha_j, \beta_j]^T\) as:

\[\mathbf{\Theta}_j = \boldsymbol{\mu}_j + \text{diag}(\boldsymbol{\tau}) \mathbf{L}_{\Omega} \mathbf{z}_j\]

Where:

  • \(\boldsymbol{\mu}_j\) is the vector of population-level predicted means for the \(j\)-th individual.

  • \(\boldsymbol{\tau}\) is the vector of among-individual standard deviations (\(\tau_{\alpha}, \tau_{\beta}\)).

  • \(\mathbf{L}_{\Omega}\) is the Cholesky factor of the correlation matrix, representing the dependency between intercepts and slopes.

  • \(\mathbf{z}_j\) is a vector of standardized deviations sampled from a unit normal distribution, \(\mathbf{z}_j \sim \mathcal{N}(0, 1)\).

Prior specification

We employed weakly informative priors for all model parameters to provide regularizing effects while ensuring that the posterior distributions remained primarily driven by the empirical data. We chose to center the priors for the global intercept (\(\alpha\)) and the effect sizes of site, year, and body mass (\(\alpha_S, \alpha_Y, \alpha_M, \beta_S, \beta_Y, \beta_M\)) at zero (\(\mathcal{N}(0, 0.5)\)). We adopted this approach as a conservative baseline assumption, reflecting a null expectation of no effect for environmental or physical covariates in the absence of strong evidence.

For the global thermal sensitivity parameter (\(\beta\)), we applied a \(\mathcal{N}(0.1, 0.5)\) prior truncated at zero. We justified this truncation based on the fundamental biological law that ectotherm metabolic rate increases with body temperature; the standard deviation of 0.5 was selected to allow the model to explore a wide range of biologically plausible thermal sensitivities.

Regarding the variance components, we assigned \(\mathcal{N}(0, 0.5)\) priors (constrained to positive values) to the residual standard deviation (\(\sigma\)) and the among-individual standard deviations (\(\tau_{\alpha}, \tau_{\beta}\)). To model the dependency between individual-level intercepts and slopes, we applied an \(\text{LKJ}(2)\) prior to the Cholesky factor of the correlation matrix (\(\mathbf{L}_{\Omega}\)). We selected a shape parameter of 2 to provide a weakly informative prior that is intentionally skeptical of extreme correlations (near \(\pm 1\)), thereby favoring a more conservative estimate of the relationship between an individual’s baseline metabolism and its thermal sensitivity.

Inference and diagnostics

Code implementation

stan code and model compilation

Below is the stan code for the resting metabolic rates model:

data{
    int<lower = 0> N; // number of observations
    int<lower = 0> J; // number of individuals
    array[N] int<lower=1, upper=J> I; // individual IDs
    vector[N] T; // temperature
    vector[N] R; // log mass-specific RMR
    vector[N] M; // mass or SVL
    vector[J] S; // site indicator
    vector[J] Y; // year indicator
}

parameters{
    // population-level fixed effects
    real a; // baseline intercept
    real <lower=0> b; // baseline slope truncated at 0
    real a_S; // effect of site on intercept
    real a_Y; // effect of year on intercept
    real a_M; // effect of body mass on intercept
    real b_S; // effect of site on slope
    real b_Y; // effect of year on slope
    real b_M; // effect of body mass on slope

    // individual-level random effects
    real <lower=0> Sigma; // residual error
    vector<lower=0>[2] Tau; // SD of individual intercepts and slopes
    cholesky_factor_corr[2] L_Omega; // Cholesky factor of correlation matrix
    matrix[2, J] Z; // standardized individual effects
}

transformed parameters {
   // define matrices to hold individual parameters and predicted means
    matrix[2, J] Theta; // matrix to temporarily hold alpha_j and beta_j
    matrix[2, J] Mu; // matrix of predicted mean intercepts and slopes

    // compute indiividual parameters
    for(j in 1:J) {
        // intercept of lizard j
        Mu[1, j] = a + (a_S * S[j]) + (a_Y * Y[j]) + (a_M * M[j]);
        // slope of lizard j
        Mu[2, j] = b + (b_S * S[j]) + (b_Y * Y[j]) + (b_M * M[j]);
    }

    // implement non-centered parameterization
    Theta = Mu + diag_pre_multiply(Tau, L_Omega) * Z;
}

model{
    // priors
    a ~ normal(0, 0.5); // population-level intercept
    b ~ normal(0.1, 0.5); // population-level slope (informative prior)
    a_S ~ normal(0, 0.5); // effect of site on intercept
    a_Y ~ normal(0, 0.5); // effect of year on intercept
    a_M ~ normal(0, 0.5); // effect of body mass on intercept
    b_S ~ normal(0, 0.5); // effect of site on slope
    b_Y ~ normal(0, 0.5); // effect of year on slope
    b_M ~ normal(0, 0.5); // effect of body mass on slope
    Sigma ~ normal(0, 0.5); // residual error
    Tau ~ normal(0, 0.5); // SD of individual intercepts and slopes
    L_Omega ~ lkj_corr_cholesky(2); // Cholesky factor of correlation matrix
    to_vector(Z) ~ normal(0, 1); // standardized individual effects

    // likelihood
    for(n in 1:N) {
        R[n] ~ normal(Theta[1, I[n]] + Theta[2, I[n]] * T[n], Sigma);
    }
}

generated quantities {
    // correlation matrix of intercept and slope
    corr_matrix[2] Omega = multiply_lower_tri_self_transpose(L_Omega);
    real Rho = Omega[1, 2]; // correlation between intercept and slope

    // estimated individual interecepts and slopes
    vector[J] a_I = Theta[1, ]'; // individual intercepts
    vector[J] b_I = Theta[2, ]'; // individual slopes

    // posterior predictions and log-likelihood for model comparison
    vector[N] R_pred; // posterior predictions
    vector[N] log_lik; // log-likelihood for each observation
    for(n in 1:N) {
        R_pred[n] = normal_rng(Theta[1, I[n]] + Theta[2, I[n]] * T[n], Sigma);
        log_lik[n] = normal_lpdf(R[n] | Theta[1, I[n]] + Theta[2, I[n]] * T[n], Sigma);
    }
}

Data preparation

We prepare the data for stan model fitting. This involves filtering out rows with missing values, recoding site information, and arranging the data by year and individual ID. We then create a list containing the necessary variables for the stan model. In particular, T (body temperature) is centered around 25 degrees and scaled by 10 as we measured four temperatures (10, 20, 30, 40) and 25 represents the middle point of the range. We also scale log_rmr_mass_specific and mass to have mean 0 and standard deviation 1.

# define function to provide initial values within prior constraints
inits <- function() {
  list(
    a = -5,
    b = 0.1,
    Sigma = 0.5,
    Tau = c(0.2, 0.2)
  )
}

# sample from model
rmr_model_fit <- sampling(
  rmr_model,
  data = rmr_stan_data,
  iter = 4000,
  warmup = 2000,
  chains = 4,
  cores = 4,
  init = inits,
  control = list(adapt_delta = 0.95, max_treedepth = 15)
)

# save fitted model

Across all populations there appears to be an extremely strong correlation between intercept and slope. This allows us to simplify each individual’s metabolic reaction norm by creating a composite value that captures both traits at the same time. We call this variable the “metabolic reaction norm” (MRN) and we define it as:

\[ MRN_i = \frac{\beta_i - \overline{\beta}}{\operatorname{SD}(\beta)} - \frac{\alpha_i - \overline{\alpha}}{\operatorname{SD}(\alpha)} \]

Code 
# define mrn
rmr_params <- rmr_params |>
  mutate(
    scaled_intercept = (intercept - mean(intercept)) / sd(intercept),
    scaled_slope = (slope - mean(slope)) / sd(slope)
  ) |>
  mutate(mrn = (scaled_slope - scaled_intercept))

# save rmr_data
saveRDS(rmr_params, "data/rmr_params.rds")
